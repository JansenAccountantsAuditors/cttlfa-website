# CTTLFA brand assets

Held brand source files. **This folder is excluded from the Xneelo deploy** (`_brand/**` in
`.github/workflows/deploy-xneelo.yml`), so nothing here is served on the public site until it is
deliberately referenced from a page. Version-controlled for safekeeping and reuse.

## Master crest
- `crest-vector-master.png` — clean transparent vector-rendered crest, 4878x5000 (downscaled from a
  9449x9685 original held on the Treasurer's machine). Preferred source for regenerating any crest
  asset. The live-site `assets/crest.png`, PWA icons and admin logo (deployed 30 Sep 2026) can be
  re-cut from this for the cleanest edges when next revised.

## #PlayAndRespect campaign (play-and-respect/)
- `playandrespect-horizontal-dark.png` — crest + #PLAYANDRESPECT lockup, transparent, white text, for
  dark/navy backgrounds.
- `playandrespect-horizontal-light.png` — same lockup in a blue bar, for light backgrounds.
- `playandrespect-sleeve.png` — #PLAY AND RESPECT sleeve/kit badge (text only, two-line).
- `badge-playandrespect.pdf` — print-ready badge (vector).
- `landscape-playandrespect.pdf` — print-ready landscape banner (vector).
- `play-and-respect-policy-draft.docx` — Play & Respect policy document, draft, proposed for adoption
  by the CTTLFA General Council. Not yet adopted.

Added 30 September 2026.
