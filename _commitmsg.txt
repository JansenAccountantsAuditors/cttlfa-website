T05 step A: publish shared foundation to window.AC (additive)

Publishes the core helpers (sb, $, esc, msg, dR, canSee, canEdit, goTab)
onto a window.AC namespace from inside the app closure, so extracted
module files can reach them. Additive only — nothing is removed and no
code path changes, so behaviour is unchanged. This is the bridge the
strict-mode closure needs before any feature module can move out.
